# The 5zig Mod — Fabric 1.21.4 port

A native Fabric 1.21.4 port of [The 5zig Mod](https://github.com/5zig/The-5zig-Mod)'s customizable HUD modules (the original stopped at Minecraft 1.13 in 2019).

**Install:** drop `the5zig-*.jar` and Fabric API (1.21.4) into `.minecraft/mods/`.

**Use:** Right Shift (or `/5zig`, or ModMenu) opens settings · F6 toggles the HUD · "Edit HUD layout" lets you drag modules, scroll to resize, right-click to snap to a corner, L = label, B = background. Timer and editor keys can be bound in Options → Controls.

**Items:** FPS, coordinates, direction/F, yaw/pitch, biome, speed, light, chunk, target block + coords, target entity health, entity count, day, server IP, players, ping, timer, clock, date, memory, CPS, AFK time, death coordinates, arrows, totems, soups, main/off hand, helmet, chestplate, leggings, boots (with durability), potion effects.

**Not ported:** everything that depended on the5zig.eu servers (friends, chat, capes, profiles — offline since 2019), the per-server minigame stats (Hypixel, Timolia, GommeHD, …), TeamSpeak/Spotify/iTunes/Logitech integrations and the plugin API.
